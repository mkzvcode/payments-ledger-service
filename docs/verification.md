E2E подтвердили сохранение сумм при 100 параллельных переводах и 100 встречных переводах без deadlock, защиту от перерасхода, конкурентную идемпотентность, точность больших целых, неизменяемость журнала, откат при lock timeout с повтором исходного ключа и проверку optimistic version.

Стандартный контейнерный прогон локально завершился ошибкой `Could not find a working container runtime strategy`. Дальнейшая настройка Docker и виртуализации прекращена по запросу автора; она не нужна для публикации исходного кода. Успешный прогон через отдельный PostgreSQL не выдаётся за успешный Testcontainers. Пропуска тестов в CI нет.

CI выполняет контейнерные проверки на Ubuntu с Docker; фактический статус появляется после публикации репозитория в GitHub. Для запуска проекта другим разработчиком сохранены инструкции Docker Compose в README.
