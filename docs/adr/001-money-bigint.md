# ADR 001: деньги в bigint

Статус: принято.

Контекст: JSON number и JavaScript number не сохраняют произвольные целые после 2^53. Ошибка округления недопустима при переводах.

Решение: суммы и балансы — PostgreSQL signed bigint, в домене — bigint внутри Money. HTTP принимает и возвращает только строки минимальных единиц. Money проверяет ISO 4217, неотрицательность и диапазон 0…9223372036854775807; платёж требует сумму >0. Число знаков ISO-валюты не меняет способ хранения; API не конвертирует основные единицы в минимальные. SQL-агрегаты используют точный numeric для защиты суммы от переполнения.

Последствия: нет конвертации денег в number/float, в том числе в мапперах и seed. Клиентам нужно явно форматировать строки. FX, проценты и округление требуют отдельной модели rational/decimal и правил округления; они вне текущего домена.
